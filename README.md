Token Radar ranks 200 pre-token protocols by an implied token value derived from a sealed DefiLlama snapshot (TVL, seven-day growth, age with no token), with a concrete farm plan for each protocol — chain-aware gas costs, a category-specific weekly action, and a hold window — plus a live-token view set aside with market caps and a model sandbox that recomputes the whole board live.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
# board: out/board.json · page: out/dashboard/index.html (open out/data.js beside it)
```
